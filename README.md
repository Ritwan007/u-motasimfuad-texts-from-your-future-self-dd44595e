One funny text message from your future self, written to `/output/entry.txt`.

> Heads up: the 'temporary' fix you're about to ship stays in production for nine years. Name it something dignified.

Entry for the [Texts From Your Future Self](https://make.fun/c/u-motasimfuad-texts-from-your-future-self-dd44595e) competition on [make.fun](https://make.fun).

## Run

```sh
node main.ts
```

Writes the 115-character entry to `/output/entry.txt` and fails loudly if it is outside 1–200 characters.
